Reasoning and protocol

Model ID openai/gpt-6-astra, reasoning effort medium, pi-mono 0.73.1. All 1,330 successful requests explicitly requested medium and all corresponding responses reported medium. Responses contained 31,194 reasoning tokens and 482 unique encrypted reasoning items. Native pi replay of encrypted reasoning after tool results was verified. The upstream weight revision beyond the model ID is not disclosed.

The native pi Responses client used a private transport that requested non-streaming upstream Responses and wrapped the unchanged reasoning, message and function-call items in SSE for the native client. No tools or reasoning items were pruned. This transport differs from the Chat Completions route in the Sonnet measurement.

One attempt per task, four concurrent workers, max_output_tokens=16384, no temperature override, Linux/bubblewrap. Source 3796b9084093e5f9383077d7bde8f1ce1f0d57b5. Task budgets were retained: long tasks up to 7200 seconds, reflection tasks up to 1800 seconds, wave 19 hard limit 120 seconds.

An initial one-task native-SSE preflight had unconfirmed reasoning and was excluded entirely. A separate native-pi tool/reasoning/replay preflight passed before this fresh 80-task run began. No earlier task results were imported or selected by score. The first task of the final run timed out and was retained as a failure.
