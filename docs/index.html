Current task set: v0.18.0

431 mechanically verified agent tasks

A compact benchmark for comparing agent harnesses on file edits, data transforms, pytest bug fixes, memory discipline, synthetic benchmark-like workflows, version-control work, skill discovery, adversarial / hostile-environment handling, CLI composition with bespoke tools whose --help must actually be read, and a long-context wave (tasks 392–411) that pushes the harness through context compaction, plus a tool-reflection wave (tasks 412–431) that requires adapting to partial results, changing constraints, and stateful service responses.
