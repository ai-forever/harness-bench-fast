What is in each benchmark?

Light · tasks 1–391: files, code, data, memory, agent workflows, Git and terminal tools.

Medium · tasks 392–471: long context (20), tool reflection (20), and wave 19 feasibility (40). The published v0.18.0 runs cover only the first 40 Medium tasks. The new wave 19 measurements cover all 80 Medium tasks.

All tasks use mechanical verification. Partial Medium results are ranked only against the same 40-task subset, separately from the current 80-task suite. Historical scores are offline rescores; the four wave 19 configurations are new complete runs. Repeat variability is unavailable for single runs.
