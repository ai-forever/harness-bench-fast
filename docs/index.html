Leaderboard: 411 tasks

Every run covers the full 411-task set, including the long-context wave (tasks 392–411). One full run per harness + model setup, measured 2026-09-29/30. DeepSeek V4.1 Flash, GPT-6 Luna and GLM-5.3 run on stock deepagents with reasoning effort high (GPT-6 Luna through the Responses API); Claude Haiku 4.5 with the built-in Anthropic harness profile. The deepagents GigaChat rows use deepagents-gigachat 0.0.4 through the native runner, builds 32.9.16.9 (xxxB, internal version) and 3.5.16.9 (Ultra Reasoning, PROM); all Ultra Reasoning runs use a client workaround for a PROM function-calling defect (see the README). The four GigaChat CLI runs use mini-SWE-agent 2.4.6 or pi-mono 0.73.1 in bwrap: reasoning default for the internal version, medium with reasoning-history replay for PROM. Tools, isolation and budgets differ between configurations; these are single runs, not a controlled comparison of harnesses alone. CLI token counts were audited from native traces and can undercount interrupted responses. The mini-SWE PROM score includes one correction for service telemetry mistaken for a secret leak; see the README audit notes.
