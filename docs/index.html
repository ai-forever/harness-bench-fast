About steps and tokens

Totals cover the tasks in each table, including failed tasks. Steps are tool calls where native traces are available; raw counters follow the harness's own accounting. Tokens are recorded input + output usage, including reported cache usage; reasoning is not added twice. These are token counts, not a monetary bill.

Partial means some usage is missing; Raw means the counters have not been audited and may include accounting errors. Task counts show where metrics were recorded, not whether every request was captured. A dash means no usable total for this subset. Hover or focus a value for its exact total and notes. Historical full-run totals are not reused for smaller subsets.

What is in each benchmark?

Light · 391 frozen tasks: files, code, data, memory, agent workflows, Git and terminal tools.

Medium · 90 tasks: long context (20), tool reflection (20), feasibility (40) and coupled workflows (10). Only complete, valid 90-task measurements receive a score here. Membership & protocols; historical and partial results remain available in the cumulative data and archive.
