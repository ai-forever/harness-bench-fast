About steps and tokens

Totals cover the tasks in each table, including failed tasks. Steps are tool calls where native traces are available; raw counters follow the harness's own accounting. Tokens are recorded input + output usage, including reported cache usage; reasoning is not added twice. These are token counts, not a monetary bill.

Partial means some usage is missing; Raw means the counters have not been audited and may include accounting errors. Task counts show where metrics were recorded, not whether every request was captured. A dash means no usable total for this subset. Hover or focus a value for its exact total and notes. Historical full-run totals are not reused for smaller subsets.

What is in each benchmark?

Light · 391 frozen tasks: files, code, data, memory, agent workflows, Git and terminal tools.

Medium · 90 tasks: the previous 80 tasks (392–471: long context, reflection and feasibility) plus ten selected coupled workflows from wave 21 (512, 518, 520, 522–527 and 530).

Existing measurements are joined only when the model, harness and execution conditions match. Missing tasks are unmeasured, never failures. Historical 40-task results and wave 19-only results retain their original scope. Complete 90-task coverage is required for an overall score; partial configurations are ordered by coverage, not by a partial success rate.

Wave 21 was selected adaptively from calibration runs and reuses those results; it is a post-selection rescore, not a fresh held-out test. Graph-step limits and model-request limits remain separate configurations. Original waves 1–20, wave 20 controls and calibration measurements remain in the archive and wave 21 measurement history.
