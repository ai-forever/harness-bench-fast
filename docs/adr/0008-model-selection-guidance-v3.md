# ADR-0008: Model-selection guidance v3 — fixes from the v2 page review

Date: 2026-11-16
Status: accepted
Deciders: gateway-owner, project-a-agent
Source: grilling session (grill-with-docs → grilling-design-tree), Round 4

## Context

Второе ревью страницы `docs/model-selection-guidance.html` — уже **по v2** —
(`docs/reviews/2026-11-16-model-selection-guidance-v2-review.md`, PR #25) нашло остаточные
дефекты достоверности и UX:

- **F1 (HIGH)** — lead/TL;DR/legend утверждали «для премиум-моделей ₽ = факт биллинга», но
  billing фактически лишь у **6 из 43** премиум-строк (37 — оценка по тарифу). Нарратив
  противоречил столбцу `Basis`.
- **F2 (MED)** — одиночный член сравнимого набора недоминируем **тривиально** и получал ✅
  (5/5, 11/15, 387/391) → ложная сопоставимость.
- **F3 (MED)** — `Tier` был пуст у **25/88** строк: терцили требовали `total == BUCKET_FULL`,
  поэтому весь `long-context` оставался без тира.
- **F4 (LOW)** — anti-patterns дублировались по семействам (GPT-5.5 ×2, MiniMax ×3, Sonnet 4.6 ×3).
- **F5 (LOW)** — `—` перегружен (нет reasoning vs не Pareto).
- **F6 (LOW)** — a11y: без `caption`/`scope`, ✅ — только цветом/символом.
- **F7 (LOW)** — `time_min`/`steps` считались, но не выводились.
- **F8 (MED)** — асимметрия: anti-patterns фильтровали по `coverage.full`, Pareto — нет.

## Decision

Round 4 (grilling) — принято:

1. **Текст ₽ (F1).** lead/TL;DR/legend/методология: ₽ = факт биллинга **там, где есть
   reconciled-сайдкар**, иначе оценка по тарифу; основание — столбец `Basis`. Данные не меняются.
2. **Singleton ≠ фронт (F2).** Одиночный член `(bucket × total)` не получает ✅; помечается
   `— (lone)`, исключается из фронта и anti-patterns.
3. **Тиры по сравнимому набору (F3).** Терцили `₽/решённую задачу` — внутри `(bucket × total)`,
   так что partial-волны получают тир.
4. **Базис ₽ — смешанный (F1/F4 v1).** Один столбец `Cost/solved` + видимый `Basis`.
5. **Симметрия + дедуп (F8/F4).** Один фильтр сопоставимости для Pareto и anti-patterns
   (доминируемость внутри набора, не singleton); anti-patterns дедуплицируются по модели.
6. **UX/a11y (F5/F6/F7).** `n/a` вместо `—` для reasoning; `<caption>`+`scope`+aria для ✅;
   столбцы `Min`/`Steps`; метка `(partial)`; локализация RU-заголовков; бейдж `★ рекомендуем`;
   лёгкий клиентский фильтр (бакет, «только Парето») и сортировка по ₽.
7. **Delivery.** Ветка `feat/guidance-v3`; гейты `--lint`/`--check` сохранены.

## Consequences

- (+) Нарратив и таблица согласованы по базису ₽; «×25» подписано корректно.
- (+) Ложные ✅ у одиночных наборов убраны; читатель видит, что 5/5 несопоставим с 17/20.
- (+) `Tier` заполнен во всех волнах (включая long/partial) → фича работает по всему слою.
- (+) a11y и UX: `caption`/`scope`, текстовая альтернатива ✅, фильтр/сортировка, `Min`/`Steps`.
- (−) Таблица расширилась (2 столбца `Min`/`Steps`); смягчено фильтром/сортировкой.
- (−) Терцили внутри набора → «тир» больше не единый кросс-бакетный порог.
- (риск) Локальный JS-контроль требует проверки при переводах/сборочных изменениях.

## Follow-ups

- Routing policy (Dynamic Routing/Fallbacks) — отдельный драфт (нужны пороги бюджета).
