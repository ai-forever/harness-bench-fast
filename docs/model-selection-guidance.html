Методология

  1. Источник — results/*.json; для премиум-лестницы ₽ из биллинга провайдера (results/reconciled/).
  2. Классификация — общий модуль scripts/fork_metadata.py (стемы совпадают с форк-таблицами).
  3. Фронт Парето — внутри каждого бакета по (pass ↑, cost_per_solved ↓); доминируемые → anti-patterns.
  4. Правило «premium оправдан»: не доминируем и (≥ +3 п.п. pass или закрыта ≥1 floor/boundary-задача).
  5. Сравнение только внутри одной task-set версии; partial = unmeasured.
