Reason for withdrawal

A raw streaming-response audit confirmed tool-call index collisions in all 186 of the 188 failed tasks that ended with invalid-argument HTTP 400 errors. Each call's separate arguments were valid JSON; concatenating them reproduced the exact invalid arguments in the replayed history rejected by the endpoint. Another 24 passing tasks also encountered this defect. This integration/protocol failure invalidates the measurement; it does not establish that the model generated malformed JSON. The retained infrastructure_failures=0 field is the originally reported runner counter: the runner did not classify these protocol compatibility failures as infrastructure.
