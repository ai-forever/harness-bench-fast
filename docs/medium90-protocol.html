Combining existing measurements

The cumulative table reuses public measurements on disjoint subsets within the same published measured configuration. It preserves original source versions, reasoning settings, harness profiles and budgets. Historical 80-task results already include wave 19; those results are counted once. Model display names alone do not establish compatibility.

Historical DeepAgents GLM and DeepSeek profiles enabled native subagents; wave 21 profiles disabled them. These remain separate. Sonnet with pi-mono and Sonnet with DeepAgents remain separate, as do 80/160 graph-step limits and Codex model-request limits. The configured uncensored DeepSeek endpoint is separate from the official model. See the linked original protocols for each measurement.

Only a valid configuration covering all 90 tasks receives an overall result, percentage and rank. Missing tasks are unmeasured, never failures. The main leaderboard ranks complete valid 90-task configurations; historical and partial measurements remain in the cumulative data and archive.

Provenance and limitations

The wave 21 component of the three small-model rows is a fresh run made on 24 October 2026 with the release profile; apart from the two fresh all-90 Haiku runs, other wave 21 components were selected from prior calibration outcomes and reused, so those stay retrospective and are not a fresh held-out evaluation. No repeat-variability interval is inferred from this projection.

Steps and tokens count final retained task attempts only. Native step units differ between harnesses. Missing counters, raw counters and incomplete request accounting remain explicit; token lower bounds are marked. Coverage of task counters does not prove complete request-level accounting.
