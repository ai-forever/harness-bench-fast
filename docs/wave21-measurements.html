Protocol and limits

Linux bubblewrap isolation; no subagents; provider-default temperature; 900 seconds, 320 trusted-service calls and 16,384 output tokens. DeepAgents 0.6.12 uses 80 or 160 graph supersteps. Configured Codex CLI 0.163.0 uses 160 model API requests, including transport retries: those units are different. The task prompt states its resource limits; runner prompt additions disclose finite graph limits. Historical 80-step results retain their original task prompts and source version.

Non-censorship API failures are retried and do not count as model failures. Censorship is a terminal failure. Historical Sonnet80 task527 retained a recovered HTTP502; it is not labelled a first-entire-clean execution. Formal run status governs scoring: Qwen task525 remains a failure despite domain goal acceptance after budget exhaustion. Configured Codex task512 remains a failure because the service-call contract was violated; it is not retried as an API failure.

Steps and tokens count only retained executions, passed and failed. Missing metrics remain unavailable; partial sums state coverage. Repeated input context is counted; cached input is already part of input tokens. Reasoning tokens are not added again to reported output totals. The configured uncensored DeepSeek on private servers is distinct from the official OpenRouter DeepSeek model. The default-catalog Codex diagnostic is excluded.

Sources are frozen calibration task sets v0.21.0 (80-step profiles) and v0.21.1 (160-step profiles); v0.21.2 selects IDs without changing the 160-step contracts. The frozen selected suite passed gold, blank-workspace rejection and frozen replay admission on all ten tasks. This release preserves current upstream trusted-service v2 runtime handling; historical results retain their original source/runtime versions and are not presented as new executions of that runtime. Calibration outcome selection and missing-counter coverage are preserved in the downloadable JSON.
