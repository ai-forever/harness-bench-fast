GigaChat-4 37b on HBF Medium

GigaChat-4 37b solved 16 of 90 tasks (17.8%) in one run with mini-SWE-agent 2.4.6 and high reasoning effort. All 90 tasks received a verifier verdict. Fourteen of the 74 failures reached the eight-hour time limit.

Run settings

Eight tasks ran in parallel. Each task had eight hours and a default budget of 100 model calls. Individual task settings could raise the call limit. The harness retained reasoning history and allowed up to 32,768 output tokens per response.

After the runner ran out of memory, it resumed from 18 saved verdicts and repeated the eight interrupted tasks. The remaining attempts ran with an 8 GiB per-process data limit and a 32 GiB memory limit for the runner.

Recorded usage

The model reported 643,102,720 input tokens and 4,713,430 output tokens across 4,609 responses from the final attempts. That totals 647,816,150 tokens across all 90 tasks. Native step counts were available for 76 tasks and totalled at least 4,389 steps.
