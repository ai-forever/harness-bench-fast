Configuration and validation

Linux bwrap with trusted host services; four workers. Task timeouts: ordinary 900 seconds, long context 7,200 seconds, tool reflection 1,800 seconds, wave 19 120 seconds. Nine task timeouts remain failures. One outcome per task; no best-of selection.

User-supplied Universal Agent profile: subagents, skills and MCP disabled; finish gate enabled with a maximum of ten iterations; up to 1,000 steps. Token compaction trigger 200,000, turn-end trigger 160,000. Maximum main output 32,768 tokens; auxiliary 8,192 and judge 10,000. Temperature omitted from every audited request.

Main calls requested reasoning enabled, auxiliary calls disabled, with default effort. The API returned no reasoning fields: actual thinking application is unconfirmed. The response model ID matched anthropic/claude-haiku-5.5; an upstream build identifier was not disclosed.

Fourteen tasks encountered HTTP 502 and were replaced by their first retry without HTTP errors, regardless of score. Recovery required five rounds and 28 additional task executions. Original artifacts were retained; the selected 471 attempts have no HTTP errors. The four-task setup smoke is excluded.

Native “Empty messages list” errors on eight long-context tasks followed main responses truncated at the 32,768-token output limit. They remain part of the measured harness behavior. Eleven finish-gate acceptances at its configured iteration limit are also retained; none resulted from a judge error. Compaction ran 43 summary batches.

Steps, tokens and recovery cost

Native terminal counters cover 462/471 tasks: 4,882 main steps and 361,609,811 tokens. All 462 token totals match API usage. Nine timed-out tasks have no terminal usage event.

Including those interrupted tasks, saved traces contain 5,447 main response steps, and API usage totals 408,049,292 tokens for the selected attempts. Across the original run and all recovery attempts, reported usage is 889,696,808 tokens, excluding the setup smoke. Input tokens include repeatedly sent context; these are not unique corpus tokens or a dollar-cost estimate.

API totals include both main and auxiliary calls. Interrupted responses that never returned usage may be missing, so API tokens and trace steps are lower bounds. Raw traces and private endpoint details stay on the benchmark server.
