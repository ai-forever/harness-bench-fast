Protocol and audit

Native pro profile, four native workers, required blocking reviews. Main reasoning effort: medium; reviewer effort: high. Output limit: 65,536 tokens. Concurrency increased from 2 to a limit of 16 tasks during the run; bubblewrap isolation; temperature was not overridden. Ordinary task guard: 3,600 seconds; long-context floor: 7,200 seconds; task-specific limits apply.

The audit retains the first authoritative completion of each task, including failed outcomes. Native runtime results and host-recorded terminal submissions are distinguished from task-created result files. Host receipts were checked against their hashes, task identity, protocol fingerprint and deadline. Recovered transport errors do not invalidate an already completed task. Later redundant attempts are excluded; this is not best-of-N selection.

Scoring revision, November 16: the benchmark owner directed that these 13 protocol errors count as harness failures. The earlier partial report (28 passes among 77 evaluated tasks) is superseded by 28/90; no tasks were rerun and no successful outcomes were added. Task timeouts also remain failures. The protocol bug itself is not fixed by this scoring change; the score measures the complete agent configuration, not model capability in isolation.
