Protocol and accounting

Model ID anthropic/claude-haiku-5.5 through OpenRouter. No temperature or reasoning override. Upstream weight revision is not disclosed. Pinned native mini-SWE-agent 2.4.6, Codex CLI 0.160.1 and Claude Code 2.1.300; native tools and context mechanics differ. One attempt per task, with retries only for terminal infrastructure errors. No best-of selection. Each harness runs four concurrent tasks in Linux/bubblewrap. Max output 16384 tokens per API response. mini-SWE-agent has no imposed step cap; Codex and Claude Code use native defaults. Ordinary tasks have a 3600-second guard and long tasks 7200 seconds. v0.19.1 accepts a timely submitted and correct wave19 answer despite a later final-reply timeout. Formal task resource budgets are unchanged. Task-set source commit 6a620b8db63c79afafb7fdea931e816ac1c95953.

Upstream response usage is captured by task session independently of agent text. Input and output tokens are summed once, with cache accounting as reported by the provider. There is no monetary billing estimate. Successful-response usage is required for every observed request; zero requests are represented explicitly. The steps column counts tool calls, not graph iterations. Raw captures and all-attempt accounting remain private. Coverage is 471/471 retained tasks per harness. Transient requests use bounded identical-body retries; unresolved errors block publication.

Codex has 11 native incomplete-response exits caused by the 16384-token output limit. Upstream finish_reason=length and native max_output_tokens errors were verified for each. All remain ordinary failed attempts, without score-based reruns; these are not network interruptions.

No independent repeated runs or repeat-based uncertainty estimate. These are agent configurations, not a controlled comparison of isolated model capability. Historical v0.19.0 scores are not relabeled or overwritten.
