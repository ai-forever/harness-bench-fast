# История версий

## 2.7.3 (2024-02)
* Исправлено: `po receive` без строк падал, если по строке заказа уже было получено
  больше половины.
* Отчёт `sheet` (инвентаризационная опись).

## 2.7.0 (2023-11)
* Комплекты (`kit`), история цен (`price`), фид маркетплейса, выгрузка для бухгалтерии.
* Отчёты `margin`, `supplier-prices`.
* Заготовки `permissions.py` и `locking.py` (не подключены).

## 2.6.0 (2023-06)
* Инвентаризация по описи (`stocktake`).
* Оплаты, взаиморасчёты, акт сверки, отчёт `debts`, напоминания о долгах.

## 2.5.0 (2022-12)
* Заказы поставщикам (`po`), частичное получение.
* Загрузка из 1С (`import-onec`).

## 2.4.0 (2022-05)
* Ценники (`label`), отчёты `history`, `dead`.
* Импорт CSV: разделитель `;`, BOM, регистр заголовков.

## 2.3.0 (2021-10)
* Скидки за количество (`breaks`), оптовая ценовая группа.
* `pricing.py`. Счёт и отчёт о продажах по-прежнему считают цены сами — синхронность
  проверяется тестами.

## 2.0.0 (2021-02) — схема 3
* Себестоимость по FIFO-слоям вместо средней. Миграция: один слой `MIGR` на остаток.
* Возвраты заказов (только целиком, SKL-212 — частичные — в планах).
* Сторно приходов.

## 1.5.0 (2020-06) — схема 2
* Остатки вынесены из карточек, документы — словарём.
* Счёт покупателю (`invoice`).

## 1.0.0 (2019-05) — схема 1
* Первая версия: товары, приходы, отгрузки, текстовое меню (`menu.py`).
