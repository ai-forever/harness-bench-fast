# Design — add-archive-ru-mirror

## Контекст

- `docs/archive.html` (1259 строк) — апстримная EN-страница, генерится/ведётся
  апстримом (коммиты #73/#74). Наш генератор её не создаёт.
- Форк-слой двуязычен по умолчанию (RU-first), см. специю `localization`.

## Решения

1. **Зеркало, а не оверрайд.** Создаём отдельный `docs/archive.ru.html`; апстримный
   `archive.html` остаётся EN и не меняется. Это сохраняет чистоту слоёв и
   отсутствие merge-конфликтов (см. `fork-doc-layering`).
2. **Переключатель.** На RU-зеркале — чип «RU · EN»: RU активен, EN ведёт на
   `archive.html`. Асимметрия осознанная: обратной ссылки на апстриме нет
   (его не трогаем); вместо этого RU-зеркало **линкуется из форк-слоя**
   (`fork.html`/`.en`, `FORK.md`), чтобы путь `fork → архив( RU )` был очевиден.
3. **Контент.** Перевод смысловых блоков RU-first; идентификаторы, версии task-set,
   имена моделей/harness и «канонические» заголовки таблиц не переводятся
   (совпадает с требованием `Канонические колонки не переводятся`).
4. **Хром.** Использовать общий форк-хром (шапка + футер с репо-ссылками), чтобы
   страница выглядела частью форк-слоя.
5. **SEO/a11y.** `<html lang="ru">`; при желании — `<link rel="alternate"
   hreflang="en" href="archive.html">` на зеркале.

## Альтернативы

- **Оверрайд `archive.html` (вариант A)** — отклонён: правит upstream-файл.
- **Stacked bilingual на одном URL** — отклонён: дублирует контент на странице и
  всё равно требует перевода; выбран зеркальный паттерн форка.

## Риски

- Объём перевода (1259 строк) → качество; решение: перевод смысловых блоков, а не
  побуквенный; QA проверяет ключевые числа/ссылки.
- Дрейф с апстримом (апстрим обновит archive.html) → периодическая сверка; страница
  зеркала помечена как «перевод, источник — EN-версия».
