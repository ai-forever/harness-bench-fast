# Design: add-billing-reconciliation

## Формат экспорта

CSV, шапка: `"date","department","api_key","model","input_tokens","output_tokens","cost"`.
`cost` — фактические ₽. Проверено: `cost ≈ input_tokens·input_rate + output_tokens·output_rate`
по тарифам Cloud.ru (напр. sonnet-4.6: 156.1M in / 1.065M out → 95 134 ₽).

## Ключи (наши)

- `kap-openclaw` — gateway/агент + OpenClaw-харнесс прогоны (`oc_*`).
- `kap-hermes` — Pi-харнесс прогоны (`pi_*`), напр. премиум-лестница.

## Инварианты

- Дедуп по полному набору полей обязателен: экспорты за разные даты перекрываются.
- Атрибуция: сопоставлять окно времени и модель прогона; остаток относить к
  «непрогонному» потреблению (сессии агента).
- Сверка с оценкой: сравнить факт с `results/**/summary.estimated_cost_rub`.

## Открытый вопрос

95 134 ₽ `sonnet-4.6` по `kap-openclaw` за 11-14→11-15: бенч-прогоны (OpenClaw-харнесс)
или собственные сессии? Отчёт должен дать разбивку по времени/модели и вывод.
